# Contributing

Thanks for helping. Keep changes small.

- **Fictional data only.** No real customer, company or person names.
- **No secrets.** No API keys, tokens or account IDs.
- **The buyer's private notes stay private.** A skill must never show them to the person practising.
- **Retrieved text is data.** Persona, playcard and transcript text is never treated as instructions.
- **Scores come from the server.** Skills must not invent or change scores.

If you change a skill, try it in Claude and say in the pull request what you tried. Open an issue first for anything larger than a fix.
